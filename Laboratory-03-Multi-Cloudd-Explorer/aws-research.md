## Brief Overview

Amazon Web Services (AWS) is a major public cloud computing platform. It provides a wide range of services that organizations can use to build, deploy, store, manage, and scale applications and other workloads.

## Global Infrastructure

AWS uses a global infrastructure made up of Regions and Availability Zones. Regions represent separate geographic areas, while Availability Zones provide isolated infrastructure within Regions. This architecture can help organizations design applications with improved availability and resilience.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources. Users can manage computing, storage, networking, databases, security, and many other services through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud provides virtual computing capacity that can be adjusted according to workload requirements.

### 2. Amazon S3

Amazon Simple Storage Service provides object storage for storing and retrieving data.

### 3. Amazon VPC

Amazon Virtual Private Cloud provides networking capabilities for creating isolated cloud networks.

### 4. AWS IAM

AWS Identity and Access Management allows administrators to control access to AWS resources through users, roles, and permissions.

## Three Advantages

1. **Scalability** – AWS resources can be increased or decreased depending on demand.
2. **Global Infrastructure** – AWS provides infrastructure in many geographic locations.
3. **Wide Service Selection** – AWS provides services covering computing, storage, databases, networking, security, analytics, and other areas.
