## Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad selection of cloud services covering computing, storage, databases, networking, security, analytics, and other workloads. Its large service portfolio allows organizations to use the same provider for many different technical requirements.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. Organizations already using Windows Server, Microsoft 365, and Microsoft identity technologies can benefit from this integration.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes workloads. Google Cloud provides AI and machine learning services as well as Google Kubernetes Engine for containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide variety of services that can support different types of projects. Its scalable infrastructure would allow me to start with a small project and expand it as requirements increase.
