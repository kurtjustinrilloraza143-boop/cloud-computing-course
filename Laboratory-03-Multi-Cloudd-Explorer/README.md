## Mission Overview

This laboratory activity explores three major public cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The purpose is to understand their infrastructure, management consoles, core services, advantages, and possible applications in different business situations.

## Cloud Platforms Explored

### Amazon Web Services (AWS)

Amazon Web Services is a cloud computing platform that provides services for computing, storage, databases, networking, security, analytics, and application development.

### Microsoft Azure

Microsoft Azure is Microsoft's public cloud platform. It provides services for computing, storage, networking, databases, artificial intelligence, security, and enterprise applications.

### Google Cloud Platform (GCP)

Google Cloud Platform provides cloud services for computing, storage, databases, networking, artificial intelligence, machine learning, analytics, and containerized applications.
