# Mission 3 Reflection

**Name:** Kurt Justin Rilloraza
**Course:** CCM101 – Cloud Computing

The cloud platform that impressed me the most during this activity was AWS because of the large variety of services it provides. I learned that AWS can support many different workloads, including websites, databases, storage systems, mobile applications, and enterprise applications. Its flexible services make it useful for both small projects and organizations with larger requirements.

AWS, Microsoft Azure, and Google Cloud have many similarities. All three platforms provide computing, storage, networking, databases, identity management, security, and monitoring services. They also provide global infrastructure that allows organizations to deploy applications and services in different geographic locations. Although their services have different names and features, they generally solve similar cloud computing problems.

Business requirements play an important role in selecting a cloud platform. Organizations should consider their budget, existing systems, application requirements, security needs, scalability, geographic requirements, and technical expertise. For example, a university that already uses Microsoft technologies may find Azure more appropriate, while an AI research company may benefit from Google Cloud's AI and machine learning services.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider requires careful analysis. The most popular provider is not automatically the best choice for every organization. A good recommendation should consider the client's actual requirements and identify services that can directly solve their problems.

My GitHub Cloud Computing Portfolio improved after completing this mission because I added organized research, comparison tables, client recommendations, Linux investigation results, and screenshots. I also gained more experience with Markdown and GitHub. Overall, this activity helped me understand how cloud platforms can be evaluated based on both technical capabilities and business requirements.
