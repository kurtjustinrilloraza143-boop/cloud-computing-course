# Client Recommendations

**Name:** Kurt Justin Rilloraza

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for the startup because it provides flexible and scalable cloud services. The company can begin with a smaller amount of infrastructure and increase resources as the number of users grows. AWS also provides services for application hosting, databases, storage, and networking. This allows the startup to build its application without investing heavily in physical hardware.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the recommended platform because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's technologies and identity services. The university can migrate selected workloads while maintaining compatibility with its current environment. Azure can also support hybrid cloud deployments.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is recommended for the AI research company because it provides services designed for artificial intelligence, machine learning, and high-performance computing workloads. Researchers can use scalable computing resources for experiments and model development. Google Kubernetes Engine can also support containerized AI applications. These capabilities make Google Cloud appropriate for a research-oriented organization.

### Recommended Services

- Compute Engine
- Google Kubernetes Engine
- Vertex AI

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended for the global e-commerce company because it provides global infrastructure and scalable services. The company can deploy applications across different locations to improve availability. Load balancing and scalable computing can help the platform handle changes in customer traffic. These features are useful for a multinational online shopping business.

### Recommended Services

- Amazon EC2
- Elastic Load Balancing
- Amazon RDS
