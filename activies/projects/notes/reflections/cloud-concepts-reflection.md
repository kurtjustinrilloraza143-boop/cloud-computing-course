Cloud computing has become an important part of my daily life because I use several cloud-based applications for communication, learning, and entertainment. Some of the services I use regularly are Google Drive, Messenger, and Canva. Google Drive allows me to store and access my files from any device. Messenger helps me communicate with classmates and family through the internet, while Canva enables me to create presentations and graphic designs online.

These services are examples of Software as a Service (SaaS) because users can access complete applications through a web browser or mobile app without installing or maintaining the software themselves. They also use the Public Cloud deployment model since they are available to anyone with an internet connection and are managed by their respective companies.

Git and GitHub are also valuable tools in cloud computing projects. Version control allows developers and students to record changes made to files, making it easier to recover previous versions if mistakes happen. GitHub provides a platform where multiple people can collaborate on the same project without overwriting each other's work. It also keeps a history of changes, making teamwork more organized and efficient.

Through this activity, I learned that cloud computing is more than just online storage. It includes different service and deployment models that make technology accessible, flexible, and reliable. I also realized that GitHub plays an important role in managing projects because it improves collaboration, tracks updates, and helps prevent errors. Understanding these concepts will help me become more prepared for future projects and careers involving cloud technologies.
